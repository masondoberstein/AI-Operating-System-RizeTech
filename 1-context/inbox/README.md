# Inbox

Drop any file here: an SOP, meeting notes, a transcript, an org chart, a policy, a handbook, a report, a screenshot. Then type **/add-doc**.

Claude reads each one, explains it in plain English, files it in the right folder (`sops/`, `meetings/`, or `documents/`), adds what it learns to your context, and puts anything that could be automated on your task list.

Word, Excel, or PowerPoint? Save it as PDF (or CSV for a spreadsheet) first.
