# SOPs

Your standard operating procedures: how things are supposed to be done. Each one is summarized in plain English (from `_template.md`), with the original file kept in `originals/`.

To add one, drop the file in `1-context/inbox/` and type **/add-doc**. Every step in an SOP that someone does by hand is a candidate for automation, so `/add-doc` also adds those to `3-capabilities/tasks-to-automate.md`.

Company wide SOPs everyone follows can also live in your company layer's handbook, if your company has one.
