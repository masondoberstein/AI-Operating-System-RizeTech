# Company handbook

The shared facts about this company, written once so every person's AI OS knows them. Read only the file that fits the question:

- `about.md`: what the company does, customers, locations, size, history
- `org-chart.md`: departments, teams, leaders, who to go to for what
- `glossary.md`: the company's words and acronyms
- `systems.md`: the main software and what each is used for
- `policies.md`: what's okay to put into AI, approvals, data rules. **Always follow these.**
- `sops/`: company wide standard operating procedures

## Rules
- These files are the company's version of the truth. If the user's own notes disagree, say so and ask which is right. Don't silently pick one.
- Never copy company handbook content into a public place.
- If something important is missing here, tell the user and suggest they ask whoever runs the company layer to add it.
