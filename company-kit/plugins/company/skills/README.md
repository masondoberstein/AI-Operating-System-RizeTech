# Shared skills

Every skill in this folder reaches everyone in the company who's connected. Each skill is a folder with a `SKILL.md` inside, the same as in a personal AI OS.

## Adding a skill
People use `/share-skill` in their own AI OS to send a skill here. Before it goes in, whoever runs the company layer checks:
1. It works on a real example.
2. Nothing personal in it (no one's name, notes, or private files).
3. No passwords or keys.
4. It follows `company-handbook/policies.md`.

After it's added, bump the version in `../.claude-plugin/plugin.json` so everyone's copy updates.
